Add a generated Public API surface at `@voyant-travel/public-api-client/generated`, typed from the
OpenAPI document, with the PK/SK capability line enforced in the types.

`paths` is every operation on the document. `PublishablePaths` narrows it to what a `pk_` key may
call, derived from the `publishable` and `guardedIntake` declarations in the resolved deployment
graph — not from the document, which says nothing about credentials. A client constructed on the
publishable subset cannot call a secret-only operation: the operation is absent from the type, so
it is a compile error rather than a runtime 403.

Both halves are regenerated by `pnpm generate:api-client` and diffed by `verify:openapi-drift`. The
hand-written surface is untouched; the generated one sits beside it so the two can be compared
before anything is repointed.

See `docs/adr/0023-generated-api-clients.md` for why the graph and the document are both required
inputs, and for the measurements behind the toolchain choice.
